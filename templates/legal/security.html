{% trans "Passwords" %}

{% trans "Passwords are never stored in plain text. We use a strong, industry-standard one-way hashing algorithm with a unique per-user salt. Failed login attempts are rate-limited via django-axes to prevent brute-force attacks." %}

{% trans "Patching & dependencies" %}

{% trans "Operating-system images and Python dependencies are updated on a regular cadence. Vulnerable packages are patched as soon as a fix is published, using pip-audit and Dependabot to track CVEs." %}

{% trans "Monitoring" %}

{% trans "Sentry monitors errors and unusual activity. Health and readiness probes verify the database and migration state. Personally identifiable information is scrubbed from error reports where possible." %}

{% trans "Access control" %}

{% trans "Production access is restricted to the maintainer. Database credentials and API keys are stored as environment variables, never committed to the repository. Admin actions are audited via Django's admin log." %}

{% trans "If we discover a breach that affects your data, we will notify the competent supervisory authority within 72 hours where required (GDPR Article 33) and inform affected users by email without undue delay (GDPR Article 34)." %}
