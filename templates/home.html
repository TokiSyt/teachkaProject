How it's
made

Teachka follows a modular Django architecture — each tool is its own app, sharing a core module for auth and data. Adding a new tool never touches existing ones.

A service/selector pattern keeps business logic clean. Groups sync across all tools automatically through Django signals.

Python
Django 5.2
PostgreSQL
Tailwind CSS
Gunicorn
Docker
